# 模板 B · 终端极简（Terminal Minimal）· 程序员审美 · 图文结合

2026-10-25 创建。与模板A（赛博夜城）并行的第二套视觉，数据 schema 完全兼容，**只换 render.py，不动 JSON**。

- 渲染脚本：`pipeline/render_template_b.py`
- 渲染命令：`python pipeline/render_template_b.py <日期>.json --outdir output_b`
- 数据样例：`samples/2026-10-25.json`（与模板A同 schema）

## 一、设计语言

| 维度 | 模板B |
| --- | --- |
| 底色 | GitHub Dark 近黑 `#0D1117` + 36px 极淡点阵（无光晕/无颗粒/无磨砂/无渐变） |
| 配色 | 语法高亮四色：蓝 `#58A6FF`（关键字）/ 绿 `#7EE787`（字符串）/ 紫 `#D2A8FF`（函数）/ 橙 `#FFA657`（常量） |
| 字体分工 | 纯拉丁/数字/命令 → Consolas 等宽；中文 → Noto Sans SC。**中文误用等宽会出豆腐块** |
| 元素 | 路径栏（`~/zero-order/ai-daily`）、行号、`##` markdown 标题、`// NOTE:` 注释块、`$` 命令行、1px 灰细线卡片、左侧主题色竖条 |
| 图文结合 | 每个板块卡右下配**迷你数据图**：行业=渐高柱（资本增长）/ 动态=折线箭头（发布节奏）/ PM=阶梯框（岗位裂变）/ 薪资=¥+横条 |

## 二、封面结构

1. 顶栏：`~/zero-order/ai-daily` + 日期（等宽）+ 细线
2. 主标题「AI 日报」132px/900 + 等宽 `v1.0` 角标
3. 注释副标 `// 过去 24 小时关注的重点`
4. 命令行 `$ ls ./sections/ --sort=hot`
5. 2×2 目录卡：行号 + 英文 key（等宽）+ 条数 + 中文板块名 + 两行钩子 + 迷你数据图
6. 底部 `$ echo "关注牛马，早八更新，更早知道"` + 细线 + 页脚（品牌名 + NO.编号/日期）

## 三、内页结构

- 页眉：`~/zero-order/ai-daily/<日期>/<序号>-<key>.md` + `0N / 04`
- 标题：`##`（主题色等宽）+ 中文 60px/900
- 「小编说」= `// NOTE:` 注释块（左侧主题色竖条）
- 条目卡：细线框 + 竖条 + 行号 + 标题（29px/700）+ 详情（22px 灰）+ `// 来源`（等宽+Noto 混排）
- 薪资页：横向条形图（细线轨道 + 主题色粗线填充 + 等宽数字）
- 总结页：CHANGELOG 风——`## 今日要点` + `// CHANGELOG · daily digest` + 5 条 `+` 卡片（四色循环）+ `$ 你怎么看？评论区唠唠`

## 四、渲染要点（坑位）

- `make_bg()` 返回 RGBA（RGB 图上 `alpha_composite` 会 ValueError）
- 所有混排中文的等宽文本必须拆分绘制：`// `、`$`、`echo ` 等纯拉丁走 `FM()`，中文走 `FS()`
- 卡片 box 坐标 `int(round())`
- 页码 `page_index` 调用方已传 1-based，渲染时直接取用（勿再 +1）
